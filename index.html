Setup (first time only)
1. Google Cloud Console で Drive API を有効化
2. OAuth consent screen: External, Publishing status = In production (Testing だと 7日で失効)
3. Scopes に drive.readonly と drive.appdata を追加
4. Web Application Client ID を作成:
   • Authorized JavaScript origins: このページの origin (例 https://gateofzen.github.io)
   • Authorized redirect URIs: このページの完全な URL (例 https://gateofzen.github.io/manga-streamer/)
5. Client ID とその隣に表示される Client Secret を上にペースト

Tip: PKCE + refresh token を使うので一度サインインすれば再認証は不要
Client Secret について: Web app タイプの OAuth client では token exchange で必須。 localStorage に保存されるので他人が触れる PC では注意。 個人利用なら問題なし。
