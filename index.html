Setup (first time only)
1. Google Cloud Console で Drive API を有効化
2. Google Auth Platform で External + Test users を設定
3. Data Access に drive.readonly と drive.appdata を追加
4. Web Application Client ID を作成、authorized origins にこのページの origin を登録
5. Client ID をここに貼り付け（localStorage に保存）

Tip: 共有用に ?clientId=... をURLに付けて開くと自動保存されます
